# CHOMS Troubleshooting

## Generic storage and media playback

Check the expected storage/export and mount ownership against the platform
storage documentation before changing permissions or mounts. Keep generic
media library paths separate from application-specific configuration.
Use non-mutating mount/capacity checks under an authorized operations task;
this document does not run them or prescribe formatting existing storage.

Service-specific troubleshooting records are preserved outside the public scope.
